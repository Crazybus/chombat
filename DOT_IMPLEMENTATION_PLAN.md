# DOT (Damage Over Time) Implementation Plan — Curare Poison

## Overview
Implement the Tupi civilization's Curare poison mechanic. This is a **new game mechanic** not currently supported by the simulator. Raw numbers (damage amount, duration) come from game data files so patch updates auto-propagate.

## Design Decisions

### 1-3-1 Pattern: How to represent DOT in the effect system
**Problem**: DOT needs damage-per-tick + duration, but the existing effect system uses `{type, attribute, value}` with single numeric values.

**Options**:
1. **New attribute + encoded value** — Add `poison_damage` attribute, encode `{damage|duration}` like the existing cls|amt pattern
2. **Two separate effects** — One for poison damage amount, one for duration (cleaner but more effects per unit)
3. **New effect type** — Create effect type 6 (DOT) that carries both values

**Recommended**: Option 1 — New attribute `poison_damage: 25` with encoded value `(duration << 8) | damage`. This matches the existing encoding pattern used for attack/armor (attribute 8/9) and keeps one effect per unit.

### Encoding Format
```
value = (duration_seconds << 8) | damage_per_tick
```
Example: 6 seconds duration, 5 damage/tick → `(6 << 8) | 5 = 1536 + 5 = 1541`

Decode: `damage = value & 0xFF`, `duration = (value >> 8) & 0xFF`

## Implementation Steps

### Step 1: `src/data/effect_constants.ts`
- Add `poison_damage: 25` to `EFFECT_ATTRIBUTES`

### Step 2: `src/data/techs.ts` (Curare, id: 1393)
- Populate `effects` array with poison effects for target units
- Archer line (`'4'`, `'2579'`, `'464'`): +5 damage/tick, 6s duration → value 1541
- Elite Archer line (`'2581'`, `'1896'`): +2 damage/tick, 6s duration → value 1538

### Step 3: `src/sim/ArmyAnalyzer.ts` (`isCombatTech`)
- Add `25` to the allowed combat attribute list

### Step 4: `src/sim/types.ts` (`UnitData`)
- Add `poisonDamage?: number` and `poisonDuration?: number` fields

### Step 5: `src/sim/Unit.ts`
- Add `poisonDamage: number` and `poisonDuration: number` constructor fields

### Step 6: `src/sim/CombatSim.ts` (`applyBonuses`)
- Handle `poison_damage` attribute (type 4 = Add): decode value, set `newUnit.poisonDamage` and `newUnit.poisonDuration`

### Step 7: `src/sim/CombatSim.ts` (DOT tick processing)
- Add `dotInstances` tracking (army-level poison sources)
- When attacker with poison hits target → create DOT instance on target
- Each tick → process active DOTs, deal damage, expire when duration elapsed
- DOT ticks every 1 second (game-standard), independent of attack cooldown

### Step 8: `src/sim/TechLogic.ts` (`getEffectLabel`)
- Add poison_damage to label map: `Poison +{damage}/{duration}s`

### Step 9: Tests (`tests/CurarePoison.test.ts`)
- Test Curare effects populate correctly
- Test poison applies to archer line, not to buildings
- Test combat sim processes DOT damage correctly

## Game Data Source
The poison values are maintained in `utils/import_game_data.py` via `_inject_curare_effects()`. When the `.dat` file parser (genieutils) supports the poison attribute, this function can be removed and the effects will be parsed directly from game data. Until then, the function injects effects during `make data` regeneration.

## Exclusions
- Defensive structures are explicitly excluded from Curare effects
- Only Tupi archer units gain poison capability
